# Dashboard Specification

## Page 1 — Portfolio Overview

- KPI cards: rent billed, rent collected, collection rate, arrears, occupancy.
- Line chart: monthly billed versus collected.
- Aging table: balance and share by arrears bucket.
- Property ranking: top five properties by arrears.
- Exception panel: open invoices, high-risk tenants, late payments, vacant units.
- Slicers: month, district, property, manager.

## Page 2 — Collections Work Queue

- Tenant table: tenant, property, unit, billed, paid, balance, oldest days, risk level.
- Bar chart: arrears by property.
- Matrix: aging bucket by manager/property.
- Drill-through target: tenant invoice history.

Color semantics: green for collected/current, amber for follow-up, red for critical arrears, and navy for structure.
