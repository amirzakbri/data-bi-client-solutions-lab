# Dashboard Specification

## Page 1 — Executive Profitability

- Cards: Revenue, Delivery Cost, Gross Profit, Gross Margin, Billable Utilization, At-Risk Projects
- Bar chart: Gross profit by project type
- Table: project risk queue with project, client, margin, hours variance, cost variance, risk
- Table or bar chart: client revenue, gross profit, and margin
- Slicers: Client, Project Type, Status, Start Date

## Page 2 — Delivery Diagnostics

- Scatter: actual hours vs budget hours, colored by risk
- Matrix: project budget, actual cost, gross profit, margin, hours variance, cost variance
- Bar chart: billable utilization by role
- Vendor-cost breakdown by cost type
- Drill-through detail for time entries

Use red for Critical, amber for Watch, and green for Healthy. Display currency in USD and percentages to one decimal.
