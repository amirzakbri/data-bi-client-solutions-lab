# Performance Test Plan

Test the initial page, month trend, category margin, top products, segment matrix, slicer interaction, and refresh. Freeze the dataset and filters. Capture three cold and three warm runs. Preserve Performance Analyzer JSON and DAX Studio exports. Attribute each duration to DAX query, visual display, or other. A reduction is accepted only when totals reconcile and the median improves; visual removal alone is not counted unless the removed visual was redundant by design.
