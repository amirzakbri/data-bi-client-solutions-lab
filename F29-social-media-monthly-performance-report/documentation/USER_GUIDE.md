# User Guide

1. Paste new exports into **Source Data** without changing column names.
2. Confirm the reporting month and platform list in **Platform Analysis**.
3. Update editable targets in **Targets**.
4. Review KPI definitions before interpreting results.
5. Check all QA controls before sharing the Executive Report.
6. Export the Executive Report to PDF or use the preview for portfolio presentation.

Organic and paid rows may coexist. Do not interpret CPC or ROAS for a platform-month with zero paid spend.
